# Easily Import and Export Word Documents in .NET MAUI Rich Text Editor using Syncfusion DocIO
 
This sample demonstrates how to **import and export Word documents in a .NET MAUI Rich Text Editor using Syncfusion DocIO**.
 
## Features
- **Import:** Convert a Word document (DOCX) to HTML and display it in the Rich Text Editor with embedded images using Base64 encoding.
- **Export:** Convert the editor’s HTML content back to a Word document (DOCX) while preserving formatting and images.
 
## Supported Platforms
- iOS
- Android
- Windows
- macOS

## Troubleshooting
Path too long exception

If you are facing a path too long exception when building this example project, close Visual Studio and rename the repository to short and build the project.
For a step-by-step procedure, refer to the Easily Import and Export Word Documents in .NET MAUI Rich Text Editor using Syncfusion DocIO.
